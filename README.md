1. This project is dedicated to the young AI Club of Shenzhen University Nantes Financial Technology Institute.
2. The project is divided into three parts: Brain, Front (end), and Model from blender.
3. Brain is responsible for the input operation and output logic of the whole model. The api.py file in the api directory stores the API key, IP, and other information for using the model, providing modular support for later model replacement. The json files in the memory directory store all standard memories that can be called, and the py files are logic functions used to look up memories based on user prompts. logic is not yet used, but can carry functions for emotion judgment and quick queries (such as time, weather, etc.) that may be needed later. The main file is the core body of the project.
4. Model from blender contains the digital avatar, currently roughly generated by Ready Player Me, pending refinement.
5. Front uses the Vue framework and serves as the front end presented to the user. You can open /Project/Front/src/App.vue directly.
6. Start the Server first, then run the .vue project.
7. The local running port is 5200.

# 🌟 Local Running Method (Universal for Mac & Windows)
## Please ensure you have Python 3.9+ and Node.js (v18+ recommended) installed, otherwise, please configure the environment first.

### Step 1: Start Backend (Flask)

```bash
cd Project                             # Navigate to the Project directory
python3 -m venv .venv                  # Create virtual environment for the first run
source .venv/bin/activate              # Enter virtual environment. Windows uses .venv\Scripts\activate
pip install -r requirements.txt        # Install dependencies
cd Brain
python3 Server.py                      # Start backend server
```

### Step 2: Start Frontend (Vue)
```bash
cd Project/Front/digital-human-front
npm install                            # Only needed for the first run
npm run dev                            # Start Vue frontend (Default port 5200)
```

### Step 3: Open Webpage
Theoretically, it is this local URL: http://localhost:5200
